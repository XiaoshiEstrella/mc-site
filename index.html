🧍皮肤设置（SkinRestorer）

服务器已安装 SkinRestorer，离线/第三方登录也能正常显示皮肤。

  • 进服后打开聊天栏，输入下方命令即可更换皮肤（/ 开头）。
  • 使用正版玩家同款皮肤：直接填对方的游戏 ID。
  • 使用 LittleSkin 皮肤站的皮肤：先在 LittleSkin 复制皮肤链接，再用「/skin set web」命令。
  • 恢复默认皮肤：使用清除命令。
    • # ① 套用某个正版玩家的皮肤（把 PlayerName 换成对方 ID）
/skin set mojang PlayerName

# ② 用皮肤链接换肤（LittleSkin / BlessingSkin 等自定义皮肤站用这个）
/skin set web classic/slim https://littleskin.cn/xxx/xxxx
# 指令中的 classic / slim 二选一填写：classic 为粗壮模型，slim 为纤细模型。
# 将指令中的 https://littleskin.cn/xxx/xxxx 替换为该皮肤的展开图直链，来源不限——皮肤库的下载链接、角色管理中的 2D 预览链接均可。
# 只要是可直接读取的皮肤展开图 URL 即可。

# ③ 清除当前皮肤，恢复默认
/skin clear

# ④ 查看该模组支持的所有命令（命令名随版本略有差异，以这里为准）
/skin help
    注意
    • 皮肤有缓存，更换后可能需要重新进服才对其他玩家可见；
    • 加载 URL 需要一定时间，以 LittleSkin 为例通常需要几秒到十几秒，请耐心等待。；
    • 请勿使用违规/侵权皮肤，服内发现将直接重置为默认皮肤。
    🏡领地须知

    保护你的家，也请把空间留给别人。

  • 手持领地工具（默认木斧/木锄，以服内提示为准），左键点击两角确定范围。
  • 按 ' 键（键盘上分号 ; 右边的引号按键）可查看/查询当前所处领地信息与边界提示。
  • 确认范围后按提示执行创建领地命令完成圈地。
    • ⚠️ 领地规则，请务必先看
    • 少设领地：只圈真正需要保护的区域，够用就好，不要大范围圈地；
    • 领地要有意义：仅用于保护建筑、营地、农场等实际内容；
    • 过量或意义不明（圈空地、圈大片荒野、圈路、圈资源点占位、多个零碎小领地）的领地，管理将直接删除，不作额外通知；
    • 长期不在线且领地内无实质建筑的，同样可能被清理；
    • 有争议请先联系管理，勿自行扩圈或与邻居对峙。
