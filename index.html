皮肤设置

SkinRestorer
聊天栏输入

/skin set mojang PlayerName

# ② 用 LittleSkin 衣柜里的角色
/skin set littleskin SkinName

# ③ 用皮肤图直链（classic 粗 / slim 细）
/skin set web classic https://...

# ④ 恢复默认皮肤
/skin clear
小提示
  • 出现 Skin changed 之类的提示即成功，可以让其他成员帮忙确认。
  • 加载链接需要几秒到十几秒（LittleSkin 常见），耐心等一下。
  • 请勿使用违规或侵权皮肤，发现会重置为默认。
  • 直链来源不限：皮肤库下载链接、角色管理的 2D 展开图片链接都可以，只要是能直接读取的皮肤展开图片。
02

领地保护

建筑安全
  1. 站在想要圈占的区块上。
  2. 按 ' 键（分号 ; 右边那个引号键）查看当前区块。
  3. 确认范围后按提示点击圈占完成圈地。
  4. 需要扩大就走到下一区块再圈一次，领地会连起来。
领地规则
  • 少设领地：只圈真正需要保护的地方，够用就好。
  • 要有意义：仅用于建筑、营地、农场等实际内容。
  • 圈空地、圈荒野、圈道路、零碎占位等会被直接删除，不再通知。
  • 有争议先联系管理，不要自行扩圈或与邻居对峙。
03

PvP 开关

双向生效
  1. /pvp on 开启：你可以攻击他人，他人也可以攻击你。
  2. /pvp off 关闭：需要 1 分钟才能生效。
  3. 这 1 分钟内不得再攻击他人，否则计时重置、重新开始。

指令提示为英文，请自行辨认；有疑问可以直接在群里问管理。

注意事项
  • 关闭后既不会被打，也无法打人——不存在「只打人不被打」。
  • 1 分钟延迟是为了防止打不过就立刻关掉 PvP 逃跑。
  • 开战前请提前友好交流，不恶意偷袭、堵门、守尸。
  • 装备与建筑损失自行承担，管理不介入正常 PvP 纠纷。
04

连锁破坏

单次 ≤ 64
  1. 按住 ~ 键（键盘左上角 Esc 下面那个键）启用连锁破坏。
  2. 保持按住挖掘，相连方块会一起破坏；松开立刻恢复普通挖掘。
  3. 对任意方块生效，一次连锁最多 64 个方块。

不需要额外需要，进服就能用。

使用注意
  • 不区分方块归属：在自家使用可能连带挖掉不想动的部分。
  • 在别人建筑内不要随手按，破坏他人建筑按服规处理。
  • 频繁大规模连锁会增加服务器负担，请适度使用。

    原地更新指南
    已装旧包、不想重下一整套？按顺序就地升级
    先看清楚你要做的是哪一种
    • 原地更新（本文）：保留现有整合包，只升级加载器 + 增删模组。
    • 重新安装：跨度太大或已改乱模组列表，直接下最新包导入更省事。
    • 无论哪种，动手前先备份数据，请一定注意。
    1. 备份存档：把 saves 整体复制一份；建议连带 config、xaero（小地图）。
    2. 升级加载器到 加载器版本 · 待填写。 版本必须与整合包要求一致，否则会加载失败或直接崩溃。
    3. 对照版本号：旧版本 · 待填写 → 新版本 · 待填写。
    4. 增删模组：
      需要添加
      添加清单 · 待填写
      需要删除
      删除清单 · 待填写
    5. 删干净旧模组：同名不同版本的两个 jar 同时存在会直接崩溃，删完按名称排序扫一眼。
    6. 版本偏移太大：先装最新完整包，能进服后再把个人客户端模组（小地图、优化类）尽量手动一一对齐。
    7. 启动自查：进服后检查背包、机器、小地图；报错大多是多了或少了某个模组。
    常见坑
    • 两个同名模组：最常见，删掉旧版本那个 jar。
    • 加载器没升级：模组要求更高的 NeoForge，启动直接失败。
    • 配置文件过期：删掉该模组的 config 让它重新生成。
    • 实在搞不定就下最新整合包重装，这样子并无任何不妥，这样更方便了你的游玩。
