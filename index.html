常见坑
  • 两个同名模组：最常见。删掉旧版本那个 jar。
  • 加载器没升级：模组要求更高的 NeoForge，启动直接失败。
  • 配置文件过期：个别模组换了配置结构，删掉该模组的 config 文件让它重新生成即可。
  • 忘了备份：出问题后无法回滚，只能重装。

皮肤设置（SkinRestorer）

服务器已安装 SkinRestorer，离线账号与第三方登录也能正常显示皮肤。

  1. 进服后打开聊天栏，输入下列以 / 开头的命令即可更换皮肤。
  2. 使用正版玩家同款皮肤：直接填写对方的游戏 ID。
  3. 使用 LittleSkin 皮肤站的皮肤：填写衣柜中对应的角色名。
  4. 使用图片直链：任何可直接读取的皮肤展开图 URL（皮肤库下载链接、角色管理里的 2D 预览链接均可）。
  5. 恢复默认皮肤：执行清除命令。
chat — 皮肤指令 
# ① 套用某个正版玩家的皮肤（把 PlayerName 换成对方 ID）
/skin set mojang PlayerName

# ② 使用 LittleSkin 皮肤站（把 SkinName 换成角色管理中对应的角色名）
/skin set littleskin SkinName
#  如果出现 HTTP connect timed out的提示，为网络的问题，请等待或更换自定义皮肤站

# ③ 使用皮肤展开图直链（自定义皮肤站用这个）
/skin set web classic/slim https://abc.com/xxx/xxxx
#   classic / slim 二选一：classic 为粗壮模型，slim 为纤细模型。
#   把链接换成该皮肤的展开图直链，只要能被直接读取即可。

# ④ 清除当前皮肤，恢复默认
/skin clear
注意事项
  • 出现 Skin changed 之类的提示就说明更换成功；不放心可以让其他成员帮忙确认。
  • 加载 URL 需要一点时间，以 LittleSkin 为例通常几秒到十几秒，请耐心等待。
  • 请勿使用违规或侵权皮肤，服内发现会直接重置为默认皮肤。
Claim & PvP

领地与 PvP

保护你的家，也把空间留给别人；打不打，由你自己决定。

圈地：三步保护你的建筑
  1. 站在你想要圈占的区块上。
  2. 按 ' 键（分号 ; 右边那个引号键）可以查看区块信息。
  3. 确认范围后，按提示点击圈占即可完成圈地；需要扩展时，走到要扩展的区块再圈占一次即可。
领地规则，请务必先看
  • 少设领地：只圈真正需要保护的区域，够用就好，不要大范围圈地。
  • 领地要有意义：仅用于保护建筑、营地、农场等实际内容。
  • 过量或意义不明（圈空地、圈大片荒野、圈道路、圈资源点占位、多个零碎小领地）的领地，管理将直接删除，不作额外通知。
  • 长期不在线、领地内又没有实质建筑的，同样可能被清理。
  • 有争议请先联系管理，不要自行扩圈或与邻居对峙。
PvP：双向开关，由你自己决定

默认情况下你既不会被打，也不能打人。想和朋友切磋，用指令打开就行。

  1. 输入 /pvp on 开启 PvP，之后你可以攻击他人，他人也可以攻击你。
  2. 输入 /pvp off 关闭 PvP——注意这不是立刻生效，见下方说明。
  3. 指令提示为英文，请自行辨认；有任何疑问可以直接在群里问管理。
PvP 是双向的
  • 关闭 PvP 的玩家既不会被攻击，也无法攻击他人——不存在「只打人不被打」的状态。
  • 开战前请提前友好交流，双方都同意再动手；不要恶意偷袭、堵门、守尸。
  • 装备与道具损失请自行承担，管理不介入玩家之间的正常 PvP 纠纷。
关闭 PvP 有 1 分钟生效延迟
  • 执行 /pvp off 后，需要 1 分钟 才会完全关闭；这是为了防止有人打不过就立刻关掉 PvP 逃跑。
  • 这 1 分钟内你不得再攻击他人，否则关闭进程会重置，1 分钟要从头重新计算。
  • 建议的做法是：打完后要明确提出结束，最后提前沟通，在决定胜负后静待双方关闭pvp。
Chain Break

连锁破坏

按住一个键，一次挖掉一整片——挖矿、清地、拆建筑都快很多。

  1. 按住 ~ 键（键盘左上角 Esc 下面那个键）即可启用连锁破坏。
  2. 保持按住的状态挖掘方块，相连的同类方块会被一起破坏，松开按键立刻恢复成普通挖掘。
  3. 对任意方块都生效，不限种类；一次连锁最多 64 个方块，超过的部分不会继续连带。
  4. 不需要在设置里开关，也不需要额外权限，进服就能用。
使用注意
  • 连锁破坏不会区分方块归属：在自家乱按可能会连带挖掉不想动的那部分，重要建筑建议先小范围试一下。
  • 在别人领地内不要随手按，破坏他人建筑会按服规处理。
  • 一次 64 个方块已经是上限；频繁大规模连锁会增加服务器负担，请适度使用。
  • 若按键无反应：先确认是英文输入法，并检查鼠标是否被其他程序占用。
Music

永无止境：音乐会（Limitless Concert）

服务器已内置 Limitless Concert 模组，合成、放置、弹奏，三步开启你的 MC 音乐会。

  1. 在工作台中即可合成模组提供的各类乐器，具体配方请自行查询。
  2. 把乐器放进快捷栏并放置到地上，靠近后右键打开乐器界面即可使用。
  3. 演奏支持两种方式：鼠标点击按键手动弹奏，或接入 MIDI 设备（如 MIDI 键盘）即插即弹。
  4. 不会弹也没关系，可以用 MID 自动播放：先下载好 .mid 文件，放进游戏目录的 config/limitless_concert/mid 文件夹，回到乐器界面点击「选择 mid 文件」选中它，再点击「打开 Mid 文件」即可自动播放。
注意事项
  • MID 播放跟随玩家：播放期间该玩家下线，音乐会立即停止；想让音乐持续请另行他法。
  • 请使用合法、无版权争议的曲谱，不要在服内播放侵权或违规内容。
  • 在公共区域演奏请控制音量与时长，避免打扰他人；有争议先联系管理协调。
  • 若 MID 未被识别：确认文件是标准 .mid 格式、已放进正确的 mid 子文件夹，并重开乐器界面刷新。
